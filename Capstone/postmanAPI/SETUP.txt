Capstone/postmanAPI
===================

Postman
-------
1. Import postman/RestCountries.postman_collection.json (optional: RestCountries.postman_environment.json).
2. Send "GET countries by subregion" — collection variables default to Northern Europe.
3. Data-driven runs: Collection Runner (or Newman) with file postman/data/subregions.csv.
   Example Newman (from repo root, with Node + newman installed):
   newman run Capstone/postmanAPI/postman/RestCountries.postman_collection.json -d Capstone/postmanAPI/postman/data/subregions.csv

SoapUI Open Source
------------------
1. Apache POI is required for .xlsx reading. Copy these JARs into <SoapUI>/bin/ext (exact versions may vary; use a matching POI 5.x set):
   poi-5.2.3.jar, poi-ooxml-5.2.3.jar, poi-ooxml-lite-5.2.3.jar, xmlbeans-5.1.1.jar, commons-compress-1.21.jar, commons-codec-1.15.jar, curvesapi-1.07.jar, log4j-api-2.17.2.jar (if prompted)
   Restart SoapUI after adding JARs.
2. File > Open: soapui/RestCountries-soapui-project.xml
3. Ensure data file exists: soapui/data/testdata.xlsx (first sheet: header row subregion, expected_region, sample_country; data from row 2).
4. Run test suite "Subregion Tests" > test case "Excel-driven GET subregion".

Generic Excel utilities (optional)
----------------------------------
soapui/scripts/ExcelReader.groovy — reusable Groovy helpers; inline script in the project demonstrates the same POI calls.
